# Сайт для первой аттестации

Простой адаптивный сайт на HTML, CSS и JavaScript.

## Файлы
- `index.html` — страницы сайта и навигация
- `style.css` — оформление сайта

## Публикация на GitHub Pages
1. Создайте новый репозиторий на GitHub.
2. Загрузите в него `index.html` и `style.css` (или все файлы из этой папки).
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. Через некоторое время GitHub покажет ссылку на опубликованный сайт в разделе Pages.
